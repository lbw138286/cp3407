# Requirements and Backlog

## Project topic
Smart Expense Tracker Web Application.

## Main user groups from Practical 2
- University student with limited monthly allowance.
- Working adult managing salary, savings, and monthly bills.
- Small business owner managing multiple expense records.

## Functional requirements
- Users can register accounts.
- Users can securely log into the system.
- Users can add expenses.
- Users can edit and delete expenses.
- Users can categorize expenses.
- Users can set monthly budgets.
- Users can receive budget alerts.
- Users can generate monthly financial reports.
- Users can analyze spending trends.
- Admin can manage user accounts.

## Capacity and velocity
The team has 3 members and works 1 day per week for 4 weeks per iteration. Therefore:

`3 members × 4 working days = 12 person-days per iteration`

This capacity was used to adjust Iteration 2 and Iteration 3 planning.
