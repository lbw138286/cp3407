## Interface prototype
The editable browser wireframe is stored at `design/ui-wireframe.html`. It records the planned page structure before the final interface. The implemented responsive interface is stored at `src/index.html` and is served by `npm start`.

The GitHub Pages navigation includes `github-pages/interface-prototype.md`, which links the wireframe, implemented interface, user stories and lecturer-feedback correction. After GitHub Pages is enabled from the repository owner account, verify the published prototype/documentation URL before submission.

No external Figma, Balsamiq, Canva or similar share link is claimed because one was not recorded during the project. The submitted evidence is the editable HTML wireframe, the executable interface, the final screenshots and the documented feedback-driven comparison.
