## Interface prototype
The final responsive UI itself is available in `src/index.html` and is served by `npm start`. The wireframe source is `design/ui-wireframe.html`; open it in a browser or import a screenshot into an online prototyping tool for presentation. The implemented page is the executable prototype and final interface.
