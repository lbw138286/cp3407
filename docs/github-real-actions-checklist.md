# GitHub Actions Required from Repository Owner

The package now contains valid issue forms, a pull-request template and a CI workflow. The following actions require access to the real GitHub repository and therefore cannot be completed inside a ZIP:

1. Push this repository, including its Git history.
2. Create a GitHub Project with Todo, In Progress and Done fields.
3. Create/close issues using `.github/ISSUE_TEMPLATE/` and link pull requests.
4. Confirm the CI workflow passes in GitHub Actions.
5. Publish the `github-pages/` documentation pages.
6. Invite Dasheng LIU using the repository collaborator settings.
7. Deploy the Node.js application to a server-capable platform and record the public URL.

Do not claim these external actions are complete until the live GitHub evidence is visible.
