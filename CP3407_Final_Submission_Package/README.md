# CP3407 Final Submission Package

## Project
Smart Expense Tracker Web Application

## Final delivered features
- User registration.
- Secure login validation and mock login testing.
- Add expenses.
- Edit and delete expenses.
- Categorize and filter expenses.
- Set monthly budgets.
- Receive budget alerts.
- Generate monthly financial reports.
- Analyze spending trends.
- Admin account display for local demo.
- System testing and bug/error tracking documentation.

## How to run the web demo
Open:

```text
src/index.html
```

Demo admin account:

```text
admin@example.com / admin123
```

## How to run tests
Use:

```bash
npm test
```
