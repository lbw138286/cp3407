# US7 - Receive Budget Alerts

## User Story

As a user, I want to receive a budget alert when my monthly spending is close to or over my budget, so that I can control my spending earlier.

## Demo Explanation

This feature compares total monthly spending with the saved monthly budget. The system can show whether the user is still safe, close to the budget limit, or already over budget.
