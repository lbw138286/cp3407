# Practical 9 - Final Summary

For Practical 9, the focus was bug/error tracking and reporting for system testing. The Smart Expense Tracker Web Application now has a clear bug reporting workflow, a structured bug log, GitHub issue templates, GitHub project board tracking guidance, and a Week 10 system testing plan.

The project moved from simple text-based user-story updates to a more formal tracking approach using GitHub Issues, Projects, labels, and Pull Requests. This makes it easier to record bugs, assign responsibility, track status, link bugs to user stories, and show evidence of fixes.

Several possible bugs were documented from system testing:

- BUG-001 for budget alert thresholds.
- BUG-002 for monthly report date filtering.
- BUG-003 for spending trend chronological sorting.
- BUG-004 for login input validation.
- BUG-005 for category naming consistency.

The Week 10 system testing plan includes 15 system-level test cases covering expense management, categorization, budgets, budget alerts, reports, trend analysis, mock login, and local storage persistence. The instructor access instruction document is also prepared so the instructor can be invited to view the GitHub repository.
