# Coursework Archive

This directory contains weekly practical work and iteration evidence completed
during the development of the CP3407 Smart Expense Tracker.

The final application is located in the repository root:

- `server/` — Node.js and SQLite backend
- `src/` — frontend application
- `tests/` — automated tests
- `docs/` — final project documentation
- `design/` and `diagrams/` — design evidence

The archived coursework is retained as evidence of the project's iterative
Agile development process.
